## ติดตั้งเป็นแอปบนมือถือ

ระบบเป็น **Progressive Web App (PWA)** ตามมาตรฐาน W3C ติดตั้งได้โดยไม่ต้องผ่าน
App Store หรือ Play Store ไม่มีค่าใช้จ่าย และอัปเดตอัตโนมัติ

| อุปกรณ์ | วิธีติดตั้ง |
|---|---|
| **Android** (Chrome / Edge) | เปิดลิงก์ → แถบ “ติดตั้งเป็นแอป” ขึ้นด้านล่าง → กด **ติดตั้ง**<br>หรือเมนู ⋮ → *ติดตั้งแอป* |
| **iPhone / iPad** (Safari) | เปิดลิงก์ → กดปุ่มแชร์ ⬆️ → เลือก **เพิ่มไปยังหน้าจอโฮม** |
| **คอมพิวเตอร์** (Chrome / Edge) | กดไอคอนติดตั้งในแถบที่อยู่ ขวาสุด |

เมื่อติดตั้งแล้วจะได้ไอคอนบนหน้าจอหลัก เปิดแบบเต็มจอ และ **ใช้งานได้แม้ไม่มีอินเทอร์เน็ต**

## ความสามารถหลัก

### สำหรับผู้เรียน
- ภารกิจสถานการณ์รายสัปดาห์ ผ่านกระบวนการ **UP TO GROW 8 ขั้น**
- แบบวัดเชิงสถานการณ์ 10 ข้อ ใช้ชุดเดียวกันทั้งก่อนและหลัง เพื่อเทียบพัฒนาการได้
- **AI Life Coach** ตั้งคำถามกระตุ้นการคิด โดยไม่ให้คำตอบและไม่ให้คะแนน
- ระบบจำจุดที่ทำค้างไว้ กลับมาทำต่อได้ทุกเมื่อ

### สำหรับครู
- **Teacher Dashboard** ติดตามความคืบหน้ารายบุคคลแบบเรียลไทม์
- **วิเคราะห์สถิติอัตโนมัติ** — t-test แบบไม่อิสระ, ดัชนีประสิทธิผล (E.I.), Cohen's d,
  ผลรายด้าน 7 ด้าน พร้อมตารางที่นำไปใช้ในรายงานได้ทันที
- **คำนวณค่า IOC** จากผลพิจารณาของผู้เชี่ยวชาญ
- **กลไกตรวจสอบความตรง 3 ชั้น** ลดอคติจากการตอบให้ดูดี
  (อ้างอิงงานวิจัย social desirability bias และ response process validity)
- สร้าง **แผนการจัดกิจกรรมโฮมรูม** และ **ใบงานฉบับพิมพ์** อัตโนมัติ
- ส่งออก CSV และพิมพ์รายงานได้ทุกหน้า

### เช็คอินใจ · Pulse (ตรวจสุขภาวะรายสัปดาห์)
- **เช็คอิน 60 วินาทีต่อสัปดาห์** เริ่มจาก "สัปดาห์นี้รู้สึกอย่างไร"
  ตามด้วยคำถามสุขภาวะ 5 ข้อ หมุนเวียนจากคลัง 14 ข้อ ครอบคลุม 6 มิติ
  (จิตใจ · เพื่อน · ความปลอดภัย · การเรียน · สุขภาพกาย · การมีคนรับฟัง)
- **ปุ่มขอความช่วยเหลือ** นักเรียนเลือกครูที่ไว้ใจให้ติดต่อกลับได้เอง
  ข้อความเห็นได้เฉพาะครูหลังรหัสผ่านเท่านั้น พร้อมช่องทางฉุกเฉินแสดงเสมอ
  (สายด่วนสุขภาพจิต 1323 · มูลนิธิสายเด็ก 1387)
- **กำแพงขอบคุณ** นักเรียนส่งคำขอบคุณถึงเพื่อนหรือครู สร้างวัฒนธรรมเชิงบวก
- **Reflections** นักเรียนเห็นประวัติอารมณ์ตัวเองย้อนหลัง 8 สัปดาห์
- **แดชบอร์ดสุขภาวะสำหรับครู** ภาพรวมทั้งห้อง แนวโน้มรายสัปดาห์ กราฟรายบุคคล
  และรายชื่อนักเรียนที่ควรเข้าไปพูดคุยก่อน เชื่อมกับระบบดูแลช่วยเหลือนักเรียนได้
- หลักการเดียวกับทั้งระบบ: **เครื่องมือไม่วินิจฉัยและไม่ตัดสินนักเรียน**
  เป็นช่องทางให้เด็กส่งเสียง และชี้จุดให้ครูดูแลได้เร็วขึ้นเท่านั้น

### ความเสมอภาคในการเข้าถึง
- **โหมดไม่มีมือถือ** — ครูบันทึกคะแนนจากใบงานกระดาษแทนผู้เรียนได้
  ข้อมูลเข้าสู่ระบบวิเคราะห์ชุดเดียวกัน
- ปรับขนาดตัวอักษร 85–160% และโหมดความคมชัดสูง
- ใช้ได้ทุกระดับชั้น ครูตั้งค่าระดับชั้นและรายชื่อเองได้

## เริ่มใช้กับห้องเรียนของคุณ

1. เปิด https://sarawut2206.github.io/LIFECRAFT-AI/
2. เมนู **ครู → ตั้งค่าห้องเรียน** → ใส่ระดับชั้น ชื่อห้อง และรายชื่อนักเรียน
3. เลือกภารกิจ → **สร้างลิงก์ / QR ให้นักเรียน** → ฉายบนโปรเจกเตอร์
4. นักเรียนสแกนแล้วเริ่มได้ทันที

> ต้องการดูตัวอย่างผลลัพธ์ก่อนใช้จริง? เมนู **เครื่องมือครูเพิ่มเติม → สร้างข้อมูลสาธิต**
> แล้วกด **ล้างข้อมูลสาธิต** ก่อนเก็บข้อมูลจริง

### เก็บข้อมูลบนบัญชีของโรงเรียนเอง (แนะนำ)

ค่าเริ่มต้นระบบบันทึกในเครื่อง หากต้องการรวมข้อมูลข้ามอุปกรณ์:

1. สร้าง Google Sheet ใหม่ → เมนู **ส่วนขยาย → Apps Script**
2. วางโค้ดจาก [`Code.gs`](Code.gs) → **Deploy → New deployment → Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
3. คัดลอกลิงก์ที่ลงท้าย `/exec` ไปวางใน `index.html` ตรงตัวแปร `API`

ข้อมูลผู้เรียนจะอยู่ในบัญชีของสถานศึกษาเอง ไม่ผ่านเซิร์ฟเวอร์กลาง
สอดคล้องกับหลักการคุ้มครองข้อมูลส่วนบุคคล

## โครงสร้างไฟล์

```
index.html              ตัวโปรแกรมทั้งหมด (ไฟล์เดียว ไม่ต้องติดตั้ง)
manifest.webmanifest    Web App Manifest สำหรับติดตั้งเป็นแอป
sw.js                   Service Worker สำหรับใช้งานออฟไลน์
icons/                  ไอคอนแอป (any + maskable ตามมาตรฐาน)
Code.gs                 สคริปต์ฝั่ง Google Apps Script (ไม่บังคับ)
```

**สถาปัตยกรรม:** ไฟล์เดียว ไม่มี build step ไม่มี dependency ภายนอก
(ยกเว้นฟอนต์ไทยจาก Google Fonts ซึ่งถูกแคชไว้ใช้ออฟไลน์)
กราฟทั้งหมดวาดด้วย SVG ที่เขียนเอง จึงทำงานได้แม้ไม่มีอินเทอร์เน็ต

## ฐานงานวิจัย

ทุกองค์ประกอบออกแบบจากงานวิจัย **28 รายการ** ทั้งในและต่างประเทศ
ดูตารางจับคู่งานวิจัยกับองค์ประกอบได้ในเมนู **ฐานงานวิจัยอ้างอิง** ภายในระบบ

หลักการสำคัญ — **AI ตั้งคำถาม ครูตัดสิน**
ปัญญาประดิษฐ์ทำหน้าที่ตั้งคำถามและร่างภารกิจเท่านั้น
ห้ามให้คำตอบและห้ามให้คะแนนขั้นสุดท้าย ครูเป็นผู้ยืนยันระดับสมรรถนะทุกครั้ง
(สอดคล้องกับกรอบ UNESCO 2024)
